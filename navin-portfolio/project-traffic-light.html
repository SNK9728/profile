Automatic Traffic Light System using Arduino UNO

Arduino UNO | Embedded Systems | C/C++

Project Image
Automatic Traffic Light System using Arduino UNO

Project Overview

The Automatic Traffic Light System using Arduino UNO is an embedded system project designed to simulate the operation of a real-world traffic signal. The Arduino UNO controls three LEDs representing the Red, Yellow, and Green traffic lights according to a predefined timing sequence.

The system demonstrates the basic concepts of microcontroller programming, digital output control, timing, and embedded system design.

Objective

To design and implement a simple automatic traffic light system using Arduino UNO that controls traffic signal LEDs in a sequential and timed manner.

How It Works

The Arduino program controls the LEDs using digital output pins and delay/timing instructions. The sequence runs automatically in an infinite loop once the microcontroller is powered on.

1

Arduino UNO starts

Microcontroller initializes GPIO pins 8, 9, and 10 as digital outputs in setup().

↓
2

Red LED turns ON

Pin 8 set to HIGH for 5000ms (5 seconds) to signal traffic to stop.

↓
3

Red LED turns OFF

Pin 8 set to LOW immediately before changing to yellow transition.

↓
4

Yellow LED turns ON

Pin 9 set to HIGH for 2000ms (2 seconds) to signal caution/transition.

↓
5

Yellow LED turns OFF

Pin 9 set to LOW prior to turning on green light.

↓
6

Green LED turns ON

Pin 10 set to HIGH for 5000ms (5 seconds) allowing traffic to proceed.

↓
7

Green LED turns OFF

Pin 10 set to LOW completing one full signal cycle.

↓
🔄

Cycle repeats automatically

The main loop() function automatically repeats the signal cycle indefinitely.

Arduino Code

traffic_light.ino C++ / Arduino 
int redLED = 8;
int yellowLED = 9;
int greenLED = 10;

void setup() {
  pinMode(redLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);
  pinMode(greenLED, OUTPUT);
}

void loop() {

  digitalWrite(redLED, HIGH);
  delay(5000);
  digitalWrite(redLED, LOW);

  digitalWrite(yellowLED, HIGH);
  delay(2000);
  digitalWrite(yellowLED, LOW);

  digitalWrite(greenLED, HIGH);
  delay(5000);
  digitalWrite(greenLED, LOW);
}

Outcome

The project successfully demonstrates an automatic traffic signal sequence using Arduino UNO. It provides a simple practical demonstration of microcontroller-based control and digital output programming.
