Project Overview

This project is an IoT-based monitoring system designed to improve the safety of elderly people living independently or in assisted care facilities.

It uses sensors such as an MPU6050 accelerometer to detect sudden falls and a DHT22 sensor to monitor environmental conditions. The system processes the sensor data using an ESP32 microcontroller and can provide real-time alerts when abnormal movement or a possible fall is detected.

Key System Features

  • Real-Time Fall Detection: Continuous threshold monitoring of 3-axis acceleration vector magnitudes to detect sudden impact and posture changes.
  • Motion and Activity Monitoring: Tracks daily movement patterns to detect prolonged immobility or unusual activity levels.
  • Temperature and Humidity Monitoring: Integrated DHT22 ambient room diagnostics to ensure safe environmental conditions.
  • ESP32-Based IoT Connectivity: Low-power wireless data telemetry streaming over Wi-Fi for remote monitoring dashboards.
  • Emergency Alert System: Instant trigger notification dispatch upon fall detection or manual panic request.
  • Continuous Elderly Safety Monitoring: 24/7 automated care oversight designed for home and healthcare environments.

Fall Detection Algorithm Snippet

// IoT Smart Elder Care System - Fall Detection Core
#include <Adafruit_MPU6050.h>
#include <DHT.h>

#define FALL_THRESHOLD 2.8 // Acceleration G-force threshold
Adafruit_MPU6050 mpu;
DHT dht(4, DHT22);

void checkElderSafety() {
  sensors_event_t a, g, temp;
  mpu.getEvent(&a, &g, &temp);

  // Calculate total acceleration vector magnitude (g)
  float mag = sqrt(a.acceleration.x * a.acceleration.x +
                   a.acceleration.y * a.acceleration.y +
                   a.acceleration.z * a.acceleration.z) / 9.81;

  if (mag > FALL_THRESHOLD) {
    triggerEmergencyAlert("CRITICAL: Sudden Fall Detected!", mag);
  }

  float roomTemp = dht.readTemperature();
  float humidity = dht.readHumidity();
  publishIoTTelemetry(mag, roomTemp, humidity);
}
