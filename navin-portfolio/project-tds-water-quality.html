Project Overview

The TDS-Based Water Quality Tester is an Arduino-based embedded system designed to measure the Total Dissolved Solids (TDS) level in water. The system uses a TDS sensor to obtain a measurement from a water sample and provides the result to the user through a display or serial monitor.

The project demonstrates sensor interfacing, analog data acquisition, microcontroller processing, and basic water-quality monitoring.

Objective

To design and develop a simple, low-cost water quality testing system using Arduino UNO and a TDS sensor to measure the dissolved-solids level of water and present the measured value in an easy-to-understand format.

How It Works

The TDS sensor detects the electrical characteristics of the water sample. Arduino UNO reads the sensor signal and processes the measurement to obtain a TDS value, generally expressed in ppm. The resulting value is displayed to the user.

What is TDS?

TDS (Total Dissolved Solids) represents the approximate concentration of dissolved substances in water. It is commonly expressed in parts per million (ppm). A TDS measurement can be useful as one indicator of water quality, but it does not by itself determine whether water is safe to drink.

Arduino Code

Sample implementation — update according to the actual sensor and calibration used.

tds_water_quality.ino C++ / Arduino 
#define TdsSensorPin A0
#define VREF 5.0      // Analog reference voltage
#define SCOUNT  30     // Sample array count

int analogBuffer[SCOUNT];
int analogBufferTemp[SCOUNT];
int analogBufferIndex = 0;
float averageVoltage = 0;
float tdsValue = 0;
float temperature = 25.0; // Default 25°C

void setup() {
  Serial.begin(9600);
  pinMode(TdsSensorPin, INPUT);
}

void loop() {
  static unsigned long sampleTime = millis();
  if (millis() - sampleTime > 40U) {
    sampleTime = millis();
    analogBuffer[analogBufferIndex] = analogRead(TdsSensorPin);
    analogBufferIndex++;
    if (analogBufferIndex == SCOUNT) analogBufferIndex = 0;
  }

  static unsigned long printTime = millis();
  if (millis() - printTime > 800U) {
    printTime = millis();
    
    // Calculate voltage
    averageVoltage = analogRead(TdsSensorPin) * (float)VREF / 1024.0;
    
    // Temperature Compensation Factor
    float compensationCoefficient = 1.0 + 0.02 * (temperature - 25.0);
    float compensationVoltage = averageVoltage / compensationCoefficient;
    
    // Convert voltage to TDS value (PPM)
    tdsValue = (133.42 * compensationVoltage * compensationVoltage * compensationVoltage 
               - 255.86 * compensationVoltage * compensationVoltage 
               + 857.39 * compensationVoltage) * 0.5;

    Serial.print("TDS Value: ");
    Serial.print(tdsValue, 0);
    Serial.println(" ppm");
  }
}
